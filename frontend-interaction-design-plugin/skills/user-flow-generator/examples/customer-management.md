## UF-01 新增客户

1. 用户进入客户列表。
2. 用户点击“新增客户”。
3. 页面打开创建弹窗。
4. 用户填写名称和邮箱并提交。
5. 页面校验输入；通过后发起创建。
6. 创建成功后关闭弹窗并刷新列表；失败时保留输入并显示错误。

```mermaid
flowchart TD
    A[进入客户列表] --> B[点击新增客户]
    B --> C[打开创建弹窗]
    C --> D{用户选择}
    D -->|取消| E[关闭弹窗]
    D -->|提交| F{表单有效}
    F -->|否| G[显示字段错误]
    G --> C
    F -->|是| H{创建结果}
    H -->|成功| I[关闭弹窗并刷新列表]
    H -->|失败| J[保留输入并显示错误]
    J --> C
```
